# Widget Grist « Nombre »

Équivalent du widget Number d'Airtable : somme, moyenne, nombre, etc. sur un groupe de lignes filtrées, avec titre, description et couleurs.

## Utilisation
1. Activer GitHub Pages sur ce dépôt (Settings → Pages → branche `main`, dossier `/ (root)`).
2. Dans Grist : ajouter un widget **Personnalisé**, coller l'URL `https://<utilisateur>.github.io/<depot>/` (ou le sous-dossier qui contient `index.html`).
3. Choisir l'accès **Accès complet au document**.
4. Configurer via l'icône ⚙ du widget ou le panneau de configuration de Grist.

La configuration est stockée dans les options du widget Grist (clé `cfg_nombre`).
